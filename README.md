# Project Analyzer 🔍

Automated analysis tool for Python projects. Extract code structure, classes, functions, dependencies, and generate AI-friendly summaries.

## Features ✨

- 📊 **Project Structure Analysis** - Scan and categorize all project files
- 🐍 **Python Code Extraction** - Extract classes, functions, and docstrings using AST
- 📦 **Dependency Detection** - Automatically find dependencies from `requirements.txt`, `setup.py`, and `pyproject.toml`
- 📄 **AI Prompt Generation** - Create comprehensive prompts for AI models
- 💾 **Multiple Output Formats** - Export analysis as Markdown and JSON
- 🎯 **Configuration Detection** - Identify config files and documentation
